# Data model

The tables, as the migrations in `backend/drizzle/` create them. Each table is
defined in its module's `infrastructure/*.table.ts`.

## `tools`

Internal applications and links staff can open from the hub.
Defined in `backend/src/modules/tools/infrastructure/tools.table.ts`.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key. Generated by the application, not the database |
| `name` | `varchar(80)` | no | — | |
| `url` | `varchar(2048)` | no | — | `http:` or `https:` only — enforced by the domain, not the database |
| `description` | `varchar(280)` | no | `''` | |
| `category` | `varchar(40)` | no | — | Free text. Grouped ignoring case in the UI |
| `created_at` | `timestamp with time zone` | no | — | Set by the application's clock |

**Indexes**

| Name | On | Why |
|---|---|---|
| `tools_name_lower_unique` | `lower(name)`, unique | Names are unique ignoring case. Only the database can enforce that when two requests arrive at once; the repository turns a violation into `TOOL_NAME_TAKEN` |

## `accounts`

Staff who may use the Gateway once approved.
Defined in `backend/src/modules/accounts/infrastructure/accounts.table.ts`.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key. Generated by the application |
| `email` | `varchar(320)` | no | — | Stored lower-case. Unique |
| `full_name` | `varchar(80)` | no | — | |
| `password_hash` | `text` | no | — | `scrypt$…` — never a plain password |
| `must_change_password` | `boolean` | no | `false` | |
| `status` | `text` | no | — | Check: `pending`, `approved`, `disabled` |
| `failed_sign_in_count` | `integer` | no | `0` | |
| `locked_until` | `timestamptz` | yes | — | Set after five failed sign-ins |
| `created_at` | `timestamptz` | no | — | |
| `approved_by` | `uuid` | yes | — | FK → `accounts.id` |
| `approved_at` | `timestamptz` | yes | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `accounts_email_unique` | `email`, unique | One account per company mailbox |
| `accounts_status_check` | check | Status is one of the three allowed values |

## `sessions`

Signed-in sessions. The cookie holds the raw token; only `token_hash` is stored.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key |
| `account_id` | `uuid` | no | — | FK → `accounts.id` on delete cascade |
| `token_hash` | `text` | no | — | SHA-256 hex of the cookie token |
| `expires_at` | `timestamptz` | no | — | Renewed on each authenticated request (7-day window) |
| `last_seen_at` | `timestamptz` | no | — | |
| `created_at` | `timestamptz` | no | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `sessions_token_hash_unique` | `token_hash`, unique | Look up a session from the cookie |

## `password_reset_tokens`

One-time public reset links. The URL holds the raw token; only `token_hash` is stored.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key |
| `account_id` | `uuid` | no | — | FK → `accounts.id` on delete cascade |
| `token_hash` | `text` | no | — | SHA-256 hex |
| `expires_at` | `timestamptz` | no | — | 24 hours from creation |
| `used_at` | `timestamptz` | yes | — | Set on first successful password set |
| `created_at` | `timestamptz` | no | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `password_reset_tokens_token_hash_unique` | `token_hash`, unique | Look up a reset from the URL token |
