# Data model

The tables, as the migrations in `backend/drizzle/` create them. Each table is
defined in its module's `infrastructure/*.table.ts`.

## `tools`

Internal applications and links staff can open from the hub.
Defined in `backend/src/modules/tools/infrastructure/tools.table.ts`.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key. Generated by the application, not the database |
| `name` | `varchar(80)` | no | — | |
| `url` | `varchar(2048)` | no | — | `http:` or `https:` only — enforced by the domain, not the database |
| `description` | `varchar(280)` | no | `''` | |
| `category` | `varchar(40)` | no | — | Free text. Grouped ignoring case in the UI |
| `created_at` | `timestamp with time zone` | no | — | Set by the application's clock |

**Indexes**

| Name | On | Why |
|---|---|---|
| `tools_name_lower_unique` | `lower(name)`, unique | Names are unique ignoring case. Only the database can enforce that when two requests arrive at once; the repository turns a violation into `TOOL_NAME_TAKEN` |

## `accounts`

Staff who may use the Gateway once approved.
Defined in `backend/src/modules/accounts/infrastructure/accounts.table.ts`.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key. Generated by the application |
| `email` | `varchar(320)` | no | — | Stored lower-case. Unique |
| `full_name` | `varchar(80)` | no | — | |
| `password_hash` | `text` | no | — | `scrypt$…` — never a plain password |
| `must_change_password` | `boolean` | no | `false` | |
| `status` | `text` | no | — | Check: `pending`, `approved`, `disabled` |
| `failed_sign_in_count` | `integer` | no | `0` | |
| `locked_until` | `timestamptz` | yes | — | Set after five failed sign-ins |
| `created_at` | `timestamptz` | no | — | |
| `approved_by` | `uuid` | yes | — | FK → `accounts.id` |
| `approved_at` | `timestamptz` | yes | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `accounts_email_unique` | `email`, unique | One account per company mailbox |
| `accounts_status_check` | check | Status is one of the three allowed values |

## `sessions`

Signed-in sessions. The cookie holds the raw token; only `token_hash` is stored.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key |
| `account_id` | `uuid` | no | — | FK → `accounts.id` on delete cascade |
| `token_hash` | `text` | no | — | SHA-256 hex of the cookie token |
| `expires_at` | `timestamptz` | no | — | Renewed on each authenticated request (7-day window) |
| `last_seen_at` | `timestamptz` | no | — | |
| `created_at` | `timestamptz` | no | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `sessions_token_hash_unique` | `token_hash`, unique | Look up a session from the cookie |

## `password_reset_tokens`

One-time public reset links. The URL holds the raw token; only `token_hash` is stored.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key |
| `account_id` | `uuid` | no | — | FK → `accounts.id` on delete cascade |
| `token_hash` | `text` | no | — | SHA-256 hex |
| `expires_at` | `timestamptz` | no | — | 24 hours from creation |
| `used_at` | `timestamptz` | yes | — | Set on first successful password set |
| `created_at` | `timestamptz` | no | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `password_reset_tokens_token_hash_unique` | `token_hash`, unique | Look up a reset from the URL token |

## `atlas_dictionary_releases`

Each released S1 dictionary ([ADR 0021](../decisions/0021-the-atlas-dictionary-changes-only-by-migration.md)).
Defined in `backend/src/modules/atlas/infrastructure/atlas-dictionary.table.ts`,
like the two tables below. Filled only by migration; nothing in the
application writes these three tables.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `release` | `varchar(16)` | no | — | Primary key, e.g. `S1 0.1.0` |
| `approved_on` | `date` | no | — | |

## `atlas_dictionary_values`

The meaning of every dictionary code, per release. 28 rows for `S1 0.1.0`.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `release` | `varchar(16)` | no | — | FK → `atlas_dictionary_releases.release` |
| `slot` | `varchar(32)` | no | — | Slot key: `productType`, `material`, `coating`, `colourClarity`, `shape`, `profile`, or `capacity` (its unit letters) |
| `code` | `varchar(5)` | no | — | Never all `0` or all `X` |
| `meaning` | `varchar(120)` | no | — | |

**Indexes**

| Name | On | Why |
|---|---|---|
| `atlas_dictionary_values_release_slot_code_pk` | `release, slot, code`, primary key | One meaning per code, per slot, per release |
| `atlas_dictionary_values_code_not_marker` | check | A value must never read as a marker |

## `atlas_slot_rules`

Which slots apply to each product type, per release. 56 rows for `S1 0.1.0`:
fourteen ruled slots for each of four product types.

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `release` | `varchar(16)` | no | — | FK → `atlas_dictionary_releases.release` |
| `product_type` | `varchar(3)` | no | — | A `productType` code |
| `slot` | `varchar(32)` | no | — | Slot key, `coating` to `thickness` |
| `rule` | `varchar(16)` | no | — | `applies`, `never`, `round_only`, `non_round_only` or `paper_only` |

**Indexes**

| Name | On | Why |
|---|---|---|
| `atlas_slot_rules_release_product_type_slot_pk` | `release, product_type, slot`, primary key | One rule per slot, per product type, per release |
| `atlas_slot_rules_rule_check` | check | Only the five rules the encoder knows |

## `atlas_spec_ids`

Saved Spec IDs. Defined in
`backend/src/modules/atlas/infrastructure/atlas-spec-ids.table.ts`. Rows are
only ever inserted: nothing in the application updates or deletes one
([ADR 0021](../decisions/0021-the-atlas-dictionary-changes-only-by-migration.md)).

| Column | Type | Null | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | no | — | Primary key. Generated by the application |
| `code` | `varchar(74)` | no | — | The whole Spec ID. Unique |
| `product_type` | `varchar(3)` | no | — | Slot 2, raw text |
| `material` | `varchar(3)` | no | — | Slot 3 |
| `coating` | `varchar(2)` | no | — | Slot 4 |
| `colour_clarity` | `varchar(2)` | no | — | Slot 5 |
| `shape` | `varchar(2)` | no | — | Slot 6 |
| `profile` | `varchar(2)` | no | — | Slot 7 |
| `capacity` | `varchar(5)` | no | — | Slot 8 |
| `top_diameter` | `varchar(4)` | no | — | Slot 9 |
| `bottom_diameter` | `varchar(4)` | no | — | Slot 10 |
| `height` | `varchar(4)` | no | — | Slot 11 |
| `length` | `varchar(4)` | no | — | Slot 12 |
| `width` | `varchar(4)` | no | — | Slot 13 |
| `gusset` | `varchar(4)` | no | — | Slot 14 |
| `unit_weight` | `varchar(4)` | no | — | Slot 15 |
| `basis_weight` | `varchar(3)` | no | — | Slot 16 |
| `thickness` | `varchar(3)` | no | — | Slot 17 |
| `variant` | `varchar(2)` | no | — | Slot 18; always `XX` for now |
| `name` | `varchar(120)` | no | — | 1–120 characters, trimmed |
| `dictionary_release` | `varchar(16)` | no | — | FK → `atlas_dictionary_releases.release` |
| `saved_by` | `uuid` | no | — | FK → `accounts.id` |
| `saved_at` | `timestamptz` | no | — | Set by the application's clock |

Slot columns hold the slot's raw text, so `0` (not known) and `X` (doesn't
apply) keep their meaning.

**Indexes**

| Name | On | Why |
|---|---|---|
| `atlas_spec_ids_code_unique` | `code`, unique | One product, one code. Only the database can enforce that against two simultaneous saves; the repository turns a violation into `SPEC_ID_EXISTS` |
| `atlas_spec_ids_saved_at_idx` | `saved_at` | Lookups answer newest first |
| `atlas_spec_ids_<slot>_idx` | each slot column from `product_type` to `thickness` | The similar lookup filters on any of them |
